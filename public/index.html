Questions

Can I analyze any website?

Use CodeShield only on websites you own or are authorized to review. It reads public files only and never logs in, submits forms or bypasses protection.

Does it find every security problem?

No. It is a static review of public source. It highlights common indicators for you to check; it is not a complete security audit.

What can I export?

All retrieved files as a ZIP, plus a Markdown report and a JSON report.

Can I edit files and download them again?

Yes. Use Find & Replace to edit or delete files in the local project, then export the updated ZIP.

Use CodeShield responsibly

CodeShield reads the public files of a website so you can review your own project, run permitted security tests and do research.

  • Scan only websites you own or have written permission to test.
  • Never use it to copy, clone or attack someone else’s site.
  • You are responsible for how you use the results.

Help & Support

Choose the right input

Analyze URL is the main tool. Enter a public website URL when you want CodeShield to discover and download the complete accessible front-end project.

Find & Replace is for searching and editing the project after a scan or ZIP import: jump to a file and line, then replace or delete.

Upload File is for local source that is not deployed. Select one or more individual files to classify and analyze them together. The same project inventory and download buttons appear after processing.

ZIP import is availableUpload a project ZIP or individual files you are authorized to inspect. The importer keeps paths bounded and lets you search and edit the local export.

If results look empty

  • Wait for the status message to say the scan is complete.
  • After a URL scan or ZIP import, open Find & Replace to search the indexed project and jump to a file and line.
  • Use Upload File / ZIP for an authorized local project; the workspace preserves paths and lets you edit or delete local files.
  • Use Download All Files (ZIP) to export the updated project after your changes.

Safety boundary

CodeShield performs bounded read-only retrieval. It does not log in, bypass access controls, submit forms, exploit targets or modify websites.

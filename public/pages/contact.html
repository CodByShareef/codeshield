Before requesting support

First confirm that you selected the correct input mode: URL for a public deployed site, Find & Replace for searching an indexed project, and Upload File for local source files or a ZIP.

Useful diagnostic details

  • The input mode and whether the source was public or local.
  • The visible status message and approximate file count.
  • The file extension or URL type involved.
  • Browser and deployment environment details, without any secrets.
Never send secretsDo not include passwords, private keys, cookies, access tokens, private source or confidential customer data in a support request or public issue.

Responsible reporting

If you discover a security issue in a site, contact the site owner through its published security channel. Do not use CodeShield output as permission for further testing.

Privacy Policy

Data minimization

CodeShield is designed to process only the source needed for the requested analysis. URL scans use a bounded read-only fetch. Pasted code and uploaded files are processed in the browser for the current session; do not submit anything confidential to a public deployment.

What not to submit

  • Passwords, API secrets, private keys, cookies, access tokens or authentication headers.
  • Private customer data, internal source code or files you are not authorized to review.
  • Archive files or disguised content intended to bypass the individual-file scope.

Network and logs

The URL fetch function may receive the public URL and retrieve its public response. Hosting providers can retain routine request metadata, error logs and security logs according to their infrastructure policies. A successful scan is not a promise that no infrastructure log exists.

Security posture

Targets are validated to block credentials, local/private address ranges, link-local targets and unsafe redirect paths. Requests use time, redirect, response-size and project-size limits. The tool does not claim that a site is secure merely because no indicator was found.

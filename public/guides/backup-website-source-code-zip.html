Back Up Your Website Source Code as a ZIP

Lost your original project folder, or moving to a new host? You can rebuild a working copy of your public frontend files from your live site and keep it as a ZIP.

This is for sites you own or manage. A live site’s public files are enough to restore the frontend, review it, or hand it to a new developer.

How to export

  1. Open CodeShield and analyze your public URL.
  2. Wait for the inventory to list HTML, CSS, JavaScript, images and fonts.
  3. Review the files and the findings so you know what you are saving.
  4. Choose Download All Files (ZIP) to save the project. You can also download a Markdown or JSON report.

What is not included

Only files the browser can download are saved. Server code, databases, uploaded media that pages never reference, and private admin areas are not part of the export. For a full backup, also back up your backend, database and hosting configuration.

Good habits after exporting

  • Store the ZIP in two places, such as cloud storage and an external drive.
  • Put the project in Git so every change is tracked.
  • Name backups with the date, for example site-2026-11-07.zip.
  • Remove any secret-like values before sharing the ZIP with others; see the exposed key guide.
  • Use find and replace to update domains before moving to a new host.
Only export what you are allowed toDownloading someone else’s site and publishing it as your own can break copyright and terms of service. Use this for your own projects or with written permission.

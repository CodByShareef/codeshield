Public Website Resource Discovery

Discover public website resources including HTML, CSS, JavaScript, JSON, images, fonts and source maps, then export a complete authorized project copy.

Modern websites are assembled from many browser-accessible resources. The main HTML document may reference stylesheets, module imports, JSON, images, fonts, manifests, source maps and additional same-site pages. Missing those files creates an incomplete review.

How CodeShield discovers resources

When you submit an authorized public URL, CodeShield follows bounded same-site links and references found in HTML, CSS and JavaScript. It validates public targets, limits redirects and file sizes, records skipped resources and packages the retrieved project into a ZIP export.

What you receive

  • A file-by-file project archive with paths and accessible resources.
  • Source inventory, response metadata, findings, dependency hints and skipped-resource details.
  • A local workspace where you can search a resource name, jump to a location and edit the downloaded copy.
Public does not mean authorizedOnly discover and review resources when you have permission. This tool is read-only and does not attempt login, access-control bypass or destructive testing.

Reading the discovered resources

Resource discovery lists the files a public page references: stylesheets, scripts, images, fonts, manifests and data files. Look for unexpected extensions, backup copies, old versions of scripts and files from domains you do not recognise. Each one is a candidate for cleanup or further review.

After discovery

Use the built-in find and replace workspace to locate a value across the whole project, and export a ZIP so you have a clean copy before changing anything.
